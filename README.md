# Open Media Collective

Simple resource-library demo for fictional nonprofit. Sample resource data lives in `app/data/resources.ts`.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

Push project to Git provider, import repository in Vercel, deploy. Vercel detects Next.js automatically; no extra configuration required.
